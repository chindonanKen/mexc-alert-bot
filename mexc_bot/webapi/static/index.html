How to teach well
  1. Pick a real trade or fire you remember.
  2. Read the snapshot — drop, band, per-TF ADs, reds (1st–5th), vol.
  3. Click the TF you actually read. The candles on that TF are the truth; chips only label the trade.
  4. Note optional color — e.g. wanted 13.0–13.2, low 13.73.
  5. Save freezes the case. Bad lesson → Delete below. Voice: “teach me about SYN — plan_ok…”
