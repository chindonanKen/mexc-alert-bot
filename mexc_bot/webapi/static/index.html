How to teach well
  1. Pick a real trade or fire you remember.
  2. Read the snapshot — drop, band, AD zone, vol (what the agent matches later).
  3. Process chips = how you traded · AD chips = did price hit your zone.
  4. Note concrete prices/why — e.g. “wanted 13.0–13.2, low 13.73 — skip · plan_ok + ad_missed”.
  5. Save freezes the case. Bad lesson → Delete below. Voice: “teach me about SYN — plan_ok…”

Process · how you traded

chip meanings
  • plan_ok — followed AD plan (incl. clean skip)
  • greed — oversized / held past plan
  • fomo — chased after the fire
  • hesitant — right idea, tiny/late size
  • pride — wouldn’t cut a failed AD
  • rule_break — broke a hard rule
  • process_skip — should have taken/skipped, didn’t
  • false_panic — looked like panic, not tradeable AD

AD zone · did price hit your buy area?

Case bucket · P2 decision class (pick one)

bucket meanings
  • ad_take — valid AD scale-in / hold plan
  • ad_press — late vol under AD → size up / add
  • ad_wait — first candles / false start / more reds needed
  • ad_skip — no AD, delist, FOMO, correct no-trade

If ad_missed: put zone prices in the note (wanted X–Y, low Z). Bucket defaults from chips if you leave it off.
